# public/icons/

PWA install icons.

## Contents

- `android-icon-144x144.png` — 144x144 launcher icon.
- `android-icon-192x192.png` — 192x192 launcher icon.

## Notes

Both icons are referenced by the web manifest generated by `vite-plugin-pwa`
in `vite.config.ts` and shipped via `includeAssets`. There is no
hand-maintained `manifest.json`.
