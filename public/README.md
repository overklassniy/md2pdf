# public/

Static assets copied verbatim into the build output.

## Contents

- `favicon.ico` — site icon.
- `icons/` — PWA install icons (referenced by the generated web manifest).
- `static/og-img.jpg` — Open Graph preview image used by `index.html`.

## Notes

The web manifest itself is generated by `vite-plugin-pwa` (see
`vite.config.ts`) — there is no hand-maintained `manifest.json` anymore.
